An entry for the [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) bounty on make.fun.

`main.py` (pure stdlib, no network) writes one line of error copy — the brutal truth about a save that failed because the disk was full — to `/output/entry.txt`:

> Our server ran out of disk space mid-save, so your file exists only as a rumor. Clear some room and try again.

The line is 110 characters, one line, inside the 1–200 character gate.
